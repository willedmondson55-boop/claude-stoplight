Claude Code Stoplight

Default 4747. The extension ships with permission for http://127.0.0.1:4747 only — picking a different port will ask for an extra permission on 127.0.0.1 when you save. Remember to start the bridge with STOPLIGHT_PORT=<port> npm start to match.

One hostname per line. The floating stoplight only appears on these sites. * means every site; github.com also matches gist.github.com. Leave empty to show the overlay nowhere (badge and notifications still work).
